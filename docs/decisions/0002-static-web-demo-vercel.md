# 0002. 발표 시연용 정적 웹 데모 추가 및 Vercel 배포

- **Status**: Accepted
- **Date**: 2026-07-27

## 배경 (Context)

명세서 §범위 제외(Out of Scope)는 "실서비스 배포(웹/앱)"를 제외하고 발표 시연을 노트북 실행 화면으로 정의했다. 그러나 Phase 1 완료 후, 발표장 시연의 전달력을 높이기 위해 웹 UI를 제작해 Vercel로 배포하기로 사용자가 결정했다. 이는 명세서 범위를 변경하는 결정이다.

## 대안 검토 (Alternatives)

| 대안 | 장점 | 단점 |
|---|---|---|
| **정적 데모 (사전 계산 재생)** | 서버·모델 호스팅·API 키 불필요, 배포 단순, 발표 당일 장애 리스크 최소, 오프라인 폴백(로컬 파일) 가능 | 실시간 추론이 아님 — 발표에서 "사전 계산 결과의 재생"임을 명시해야 함 |
| 실시간 평가 포함 | 시연 임팩트 큼 | 배깅 모형(수백 MB) 서버리스 호스팅 난이도, LLM 실시간 호출 시 API 키를 배포 환경에 노출, 당일 장애 리스크 |
| 노트북 유지 (변경 없음) | 추가 작업 0 | 발표 화면 산만, 시연 전달력 낮음 |

## 결정 (Decision)

1. **정적 단일 페이지 데모를 채택한다**: `webdemo/index.html` (자체 완결형 — 외부 라이브러리 없음).
2. 데이터는 노트북이 산출한 실제 결과를 그대로 임베드한다: 사례 3건의 PD·판정, SHAP Top 5(표시값은 display_value 규칙 적용), Claude 생성 설명문(explanations_cache.json), Counterfactual 결과, 공정성 감사 지표.
3. 실시간 모형 추론·LLM 호출은 포함하지 않는다(API 키 비노출). 페이지에 "사전 계산 결과 재생"임을 명시한다.
4. 제작은 채팅 세션(디자인 담당), 커밋과 Vercel 배포는 Claude Code(실행 환경 담당)가 수행한다.
5. 시각 규칙: SHAP 기여도는 다이버징(위험증가=적색/완화=청색), 공정성 그룹은 카테고리컬 2색, 라이트/다크 모드 지원, 표(테이블) 병기.

## 영향 (Consequences)

- 명세서 §범위 제외 개정 필요: "시연용 정적 웹 데모(Vercel 배포)는 범위에 포함, 실시간 추론 서비스는 여전히 제외"로 해석한다(명세서 본문의 해당 절에 이 ADR 번호를 참조로 추가 가능).
- 발표 시연 = 배포 URL. 폴백 1 = 로컬 index.html 직접 열기, 폴백 2 = 노트북 캐시 모드 (ADR-0001).
- ⚠️ Vercel 기본 배포 URL은 링크를 아는 사람은 접근 가능 — 발표 전 과제물 유출 방지를 위해 URL을 공유하지 않고, 필요시 Vercel Deployment Protection을 검토한다(발표장 접속 편의와 trade-off).
- ⚠️ 데모 수치는 노트북 산출물과 동기화 상태를 유지해야 함 — 노트북 재실행으로 수치가 바뀌면 webdemo 데이터도 갱신 필요(문서-코드-수치 정합성).
